# Changelog

All notable changes to this project are documented here.

## Unreleased

### Added

- First public release: one command that sets up a Mac with the Xcode command line tools, Homebrew and a Brewfile, a zsh profile and prompt from public dotfiles, tool configs from public repositories, developer toolchains and captured macOS settings. Every stage checks first, so a re-run on a set-up Mac changes nothing.
- The High Contrast terminal palette for Terminal.app and iTerm2, following light and dark mode.
- Opt-in extras for VS Code extensions and an OrbStack Ubuntu machine.
- Offline tests that run on the stock macOS bash 3.2.
